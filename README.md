# Riding Shotgun

A Starsector mod for 0.98a-RC8.

> **Status: prototype.** Work in progress, not ready for play. Expect bugs, missing features and save-breaking changes.

Adds the **Dual Command Interface** hullmod, which gives a ship a second officer seat. The second officer's
combat skills apply to the ship, except skills the captain already has. Second officers can be assigned from the
refit screen and from the fleet screen, and are shown next to the captain's portrait in the fleet screen and in
combat.

Not done yet: XP for second officers, moving the higher-level officer into the captain's seat automatically,
second officers on ship modules.

## Requirements
- PatchLib
- LazyLib
- MagicLib
- LunaLib
- GraphicsLib

## Building
Open the folder in IntelliJ and build the `RidingShotgun:jar` artifact (outputs to `jars/RidingShotgun.jar`), or run `build.sh`.
