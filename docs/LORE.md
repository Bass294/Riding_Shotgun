# Riding Shotgun lore

Facts the author has established. Text Claude drafted is not recorded here until the author approves it.

## Places

- **Research Station Gemini**: a relic station, one in the sector, defended by Remnants. (2026-10-22)

## Characters

- **Cecilia Corabelle**: female; an archivist who points the player to Research Station Gemini at bars; uses the vanilla
  portrait portrait_league07. (2026-10-22)
  Introduces herself only as "CC"; reads a paper book in the bar. Wants a copy of the station's public employment
  registry, since some of the greatest pre-collapse minds are recorded visiting it. (2026-10-23)

- **Gemini Core**: an AI core commanding the station's defenders from a Radiant with 3 s-mods; has all 14 vanilla
  combat skills at elite; has its own portrait. (2026-10-22)

## Items

- **Gemini Core** (item): recovered from Research Station Gemini; not an AI core; required to install the Dual
  Command Interface. (2026-10-22)

## Hullmods

- **Dual Command Interface**: costs the same OP as Neural Interface (3/6/9/15); raises deployment cost by 8% for each
  skill the second officer adds (skills the captain already has don't count). (2026-10-22)

## Terms

- **Co-pilot**: the player-facing name for the second officer seat the Dual Command Interface adds. Code, save keys and
  log messages still say "second officer". (2026-10-22)
